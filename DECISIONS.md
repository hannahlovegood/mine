- 2026-09-06 · Plain API for the extension (EXTENSION.md §4): `POST /api/plain` `{ lang: 'en'|'zh', blocks: 1–12 × { id, text (1–1500 chars), kind: text|legal|instruction|faq|notice|deadline|field-help|decision-label } }` → `{ rewrites: [{ id, plainText, terms: [{ term, plain }] }], ms }`; shared handler `server/plain.ts` behind the Vercel function `api/plain.ts` and the Vite router. One batched completion (JSON mode where supported, temperature 0, 200 tokens per block capped at 2400, 12 s deadline, retry once with the parser error). §11's number rule is enforced by the server, not entrusted to the prompt: a rewrite is dropped, never patched, when its digit multiset differs from the original, its length leaves the 20 %–130 % window, or it introduces a URL; `legal` and `decision-label` blocks come back as short summaries for display beside the original. Terms are filtered rather than dropped with the block: kept only when they appear verbatim in the original, carry a definition, and add no digit run or URL, at most the first 4. No key → `503 { error: 'no-model' }` (the demo's build-time plain content is unaffected); model failure or timeout → `200 { rewrites: [] }`.
