# 由我 Mine · 三分钟 Demo 讲稿（中文）

场地规则：3 分钟 Demo + 1 个问题；不介绍自己；重点在产品与技术实现；台下 builder 互投。
所以每一句都要让一个做产品的人点头，而不是让评委打分。

## 上台前（30 分钟）

- 终端 A：`cd ~/Documents/Claude/mine && npm run demo`，浏览器开 `http://localhost:4173/?demo=1&lang=zh`，全屏，缩放 100%。
- 浏览器另开一个标签：真实网站（见下方「真实站点」），已装好扩展，先点一次「变成我的」确认能用，再点「回到原版」放着。
- 备份视频 `docs/recordings/mine-demo-zh.webm` 在第二个窗口开好。
- 关通知、关其它标签、手机热点待命。数字键 1 → 6 → r 走一遍。

## 讲稿（2:50，留 10 秒静默给最后一句）

**0:00 · 开场**（按 `1`，屏幕上是原版政务页）
每一个界面都预设了一位读者。这个页面预设的读者，有时间、注意力完美、还耐得住术语。

**0:15 · 问题**
它通过了自动化无障碍检测，零违规。现在请找截止日期——在第四段。表单一共十二项，拉到底部，还有一项你已经「同意」了的东西：默认勾选的数据共享。
（停两秒，让大家看。）

**0:40 · 变成我的**（按 `2`，等形变和右侧数字跳完）
十二个填写项变成五步。截止日期移到最上面。收起了十八项，没有一项是关键信息，清单在右边。还有一个选择被揭示出来：那项数据共享授权原本默认勾选，它是可选的。我们没有替你取消勾选，我们只是确保你看见了它。

**1:15 · 我的话**（按 `3` 预填，按 `4` 应用）
现在告诉它你希望页面是什么感觉。「长表单让我喘不过气。用大白话，解释我可能不懂的词，一次只让我做一个决定。」它把我的话变成一份配置，并且告诉我为什么：「一个决定」变成了每步一件事。所有蓝色的地方都是它改过的，所有蓝色的地方都能撤回。

**1:45 · 改变主意**（按 `5` 按住、松开；点「回到原版」）
没有任何决定是替你做的，也没有任何东西丢失。自由包括改变主意的权利。

**2:00 · 真实网站**（切到另一个标签，点工具栏图标，侧边栏出来，点「变成我的」）
这不只是一个演示页。这是一个 Chrome 扩展，在你真正要办事的网站上原地重排：真表单还是真表单，你在真输入框里填、用真按钮提交，它只负责收起、提前、分步、揭示、撤回。这是刚才那个引擎，跑在别人的网页上。

**2:30 · 诚实与技术**
技术上只有三层：网页抽成块结构，一个纯函数引擎按九条规则重排，输出的改动清单就是你看到的账本，每个数字都是算出来的，不是写出来的。引擎有八条不变量测试：关键信息不会消失，数字在平实版里不会变，预勾选永远不被翻。真正难的是从任意网页认出这套结构，我们用九种页面形状和七个真实站点在验证。

**2:45 · 收尾**（按 `6`）
这就是「由我」。无障碍给你入口，自由给你掌控。
（静默，让最后一行落下。）

如果模型调用失败：徽章会显示「离线规则理解」。说一句：「网络断了，这是离线解释器，行为一样，理由还在。」继续。

## 唯一那个问题，可能的答法

- 「和阅读模式有什么区别？」阅读模式解决读，我们解决办：表单、决定、截止日期。阅读模式不会告诉你这个页面要你做两个决定。
- 「能用在真实网站吗？」刚才那一拍就是。识别是启发式的，认不出的块一律不动，关键内容有不变量兜底。
- 「为什么不直接让 AI 替用户填？」委托不等于自主。Agent 替你做，你仍然不知道自己同意了什么。我们改界面，不替人做决定。
- 「简化的文本可信吗？」平实版每一个数字必须原样出现，否则整段丢弃；法律条款从不替换，只并列摘要；每段改写标蓝、一键看原文。
- 「谁会用？」用户侧：政务、银行、医疗这些高压页面的读者；机构侧：作为 SDK 让公共服务网站提供「合身版」。合规不等于可用。
